# 部分空位托盘跳过测试设计

## 目标

通过托盘码加载电芯码后，只测量实际绑定了有效电芯码的通道。托盘有空位时跳过这些点位，缩短测试时间，并确保空位不会进入复测或 PLC NG 分档。

## 范围

- 覆盖主测试页通过托盘码准备的 PLC 自动测试周期和主测试页手动测试周期。
- 独立的手动测量窗口不加载托盘码和电芯码，不属于本次范围。
- 调试模式为本次计划中的通道生成临时电芯码，保持现有行为。
- 不改变 R160、R161、R152、R162 握手顺序，也不改变有效电芯 NG 的 DT 地址或档位。

## 通道计划规则

托盘数据读取后，继续校验通道号范围、重复通道和重复电芯码。缺少数据行、`BatteryCode` 为 `NULL`，或电芯码去空格后为空，均代表该通道没有有效电芯，不纳入测量计划。无效通道、重复绑定等结构错误仍使托盘准备失败。

| 模式 | 实际测量通道 |
| --- | --- |
| PLC 自动测试 | 托盘中所有有有效电芯码的通道 |
| 主测试页手动测试 | 操作员已选通道与有有效电芯码通道的交集 |

如果托盘没有任何有效电芯码，托盘准备失败，不发送 R160，也不开始测试。如果手动模式所选通道与所有有电芯码的通道都不重叠，同样在托盘准备阶段失败，并提示所选通道没有可测电芯。部分通道缺码时，只跳过缺码部分，剩余有效通道照常测试。

## 组件与数据流

1. `TrayTestPreparation.Prepare` 从已验证的电芯码集合建立实际测量通道列表。自动模式使用全部有效通道；手动模式先验证选择，再与有效通道取交集。`OccupiedChannels` 表示该计划中实际可测的有电芯通道。
2. 自动周期将计划中的有效通道交给初测入口。手动周期的托盘准备接口返回计划中的有效通道，协调器将其作为周期不可变快照保存，供测试入口、状态校验和结果处理共同使用。
3. 自动测试就绪判断接受一个或多个有效通道，而不要求计划必须含 256 个通道。自动测试事件中的通道数量使用实际计划数。
4. NG 复测仍只处理初测结果中的 NG 通道。最终结果和 PLC NG 选择仍基于测试结果；空位不产生测试结果，因此没有对应的 DT NG 档位写入。

## 错误处理与 PLC 行为

- 托盘查询、通道完整性、重复电芯码的现有失败路径保持不变。
- 空托盘及手动选择完全没有有效电芯的托盘在发送 R160 前失败，不进入测试流程。
- 有效通道的采集失败仍按现有测试失败规则处理。
- 只跳过没有电芯码的通道。有效电芯的 NG 仍按现有逻辑写入 PLC；完成握手和空 NG 集合的既有行为不变。

## 验收标准

1. 自动模式下，部分空位托盘只执行有有效电芯码的通道，周期快照与实际执行列表一致。
2. 主测试页手动模式下，只执行所选且有有效电芯码的通道；缺码选择不再阻止其他有效通道测试。
3. 托盘无有效电芯码，或手动所选通道均无有效码时，不创建可执行周期、不发送 R160。
4. 通道数据错误和重复电芯码仍被拒绝。
5. 空位不进入 NG 复测集合、最终结果通道集合或 PLC DT NG 写入列表；有效通道的 NG 档位和 PLC 握手保持原有行为。
