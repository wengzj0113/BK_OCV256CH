# 自动模式全选通道设计

## 目标

主测试页每次进入自动模式时，立即将 256 个通道设为已选中，不受此前手动模式通道选择影响。手动模式继续允许操作员选择部分通道。

## 方案

复用 `ChannelGridControl.SelectAll()`，在主测试页完成自动/手动互斥状态更新后，自动模式选中时立即调用。程序化恢复到自动模式的 `SetTestMode(True)` 路径也执行全选，确保自动模式的所有入口遵循同一规则。应用启动时已有全选逻辑，继续保留。

此改动只负责同步通道选择状态和现有界面刷新事件，不改变自动测试计划、手动模式选择行为或 PLC 流程。

## 验收条件

- 手动模式选中任意部分通道后切到自动模式，256 个通道全部选中。
- 程序化恢复到自动模式时也全选。
- 手动模式仍可以取消部分通道选择。
