# PLC 客户握手流程与 NG 挑选地址设计

> 本文件按客户 2026-10-06 流程说明更新。此前基于 R170、全区清零和托盘物理行列转置的设计已被本协议取代。

## 1. PLC 信号合同

自动流程由 PLC 信号驱动，R160、R161、R162 是上位机分别对三个阶段的完成确认：

1. **托盘识别：**上位机检测 R150=1 后触发扫码并读托盘码。条码为空、读取失败或长度校验不通过时提示手工输入。有效托盘码和托盘数据准备完成后发送 R160=1。
2. **测试：**等待 R150 复位并完成 R151 低电平准备后，检测 R151=1 开始本托盘测试。初测和已配置的 NG 复测全部完成、最终测试结果保存成功后发送 R161=1。
3. **NG 挑选：**需要分选的阶段在 R161 后等待 R152=1。只对复测后的最终 NG 序号写档位 2；每次 DT 写入确认成功后，发送 R162=1。R162 确认前不得进入下一托盘流程或读取下一次 R151。

每个 PLC 请求共用现有同步串口锁，信号读取和 ACK 错误不得当成信号低或写入成功。R161 ACK 重试不能重新测量或保存结果；DT 写入未全部确认时不发送 R162；R162 ACK 重试不能重复测试或重复发布结果。

不需要 NG 挑选的 OCV 阶段在结果保存后发送 R161，跳过 R152、DT 和 R162。

## 2. DT 地址语义

DT1001–DT1256 是 PLC 的 NG 挑选地址序列，不是托盘物理坐标，也不使用设备通道号与托盘标准号的物理位置变换。

最终 NG 逻辑序号 n（1–256）对应：

    DT address = 1000 + n
    grade = 2

例子：NG 序号 1→DT1001、2→DT1002、16→DT1016、256→DT1256。全 256 个地址与逻辑序号一一对应。

OK 序号不发送任何 DT 写入，包括不写 0。PLC 必须根据自己的设备时序确保下一托盘开始前旧 NG 标记已清除；此项需现场核实 PLC 程序。软件在没有该合同之前不得自行发明 OK 档位或全区清零动作。

TrayChannelMapping 继续用于测量执行时的设备通道号与托盘标准编号转换；PLC 挑选地址的线性编号不复用该物理映射。

## 3. 失败与恢复

- 无效扫码或 PLC 扫码失败：请求人工托盘码；取消或无效输入时不写 R160。
- R160 未确认：不进入 R151 测试阶段。
- 测试、复测或最终结果持久化失败：不发送 R161。
- R161 未确认：仅重试 R161。
- R152 未到位：保存结果后等待，不写 DT，不发送 R162。
- 任一 NG DT 未确认：保留本轮最终 NG 集合并重试；重复写入同一 NG=2 是幂等的。
- R162 未确认：仅重试 R162；未确认之前不释放本托盘或接受下一次 R151。

## 4. 自动流程状态边界

    Idle
      → R150=1
      → ReadingTrayCode / WaitingManualTrayCode
      → PrepareTray + R160
      → WaitingR150Reset
      → ArmingR151 → WaitingFixturePressed
      → InitialTesting / AutoRetesting
      → Finalizing + R161
      → (需要分选) WaitingR152
      → WriteFinalNgGrades
      → WriteR162
      → ResetCycle → Idle

不需要分选的阶段在 R161 确认后等待当前 R151 复位，再重置周期。分选阶段在 R162 确认后释放周期；下一次测试仍先经过新托盘 R150/R160 阶段。

## 5. 验收条件

1. R150=1 触发扫码；无效码进入手工输入；有效码后才发送 R160。
2. R151=1 启动唯一一次初测；所有配置复测及结果保存后发送 R161。
3. R161 后 R152=0 时不访问 DT、不发送 R162；R152=1 才发送最终 NG 集合。
4. 只写 grade=2；任意 OK、空位或 NG 复测转 OK 不发送 DT 写入。
5. 逻辑序号 1、2、16、256 分别映射 DT1001、DT1002、DT1016、DT1256；所有序号无重复、无遗漏。
6. 所有 NG DT ACK 前不发送 R162；R162 未确认前不进入下一托盘流程/读取下一次 R151。
7. 扫码、R161、部分 NG DT、R162 的失败恢复不得重复测量或保存。
8. 现场连续多托盘核验 PLC 清除 DT 旧值和 R150/R151/R152 信号边沿；未通过现场验收时只报告软件验证通过。
