# 用户权限与会话状态设计

## 1. 目标

完善 `MDIForm` 的管理员、操作员和未登录状态，使权限划分在界面入口和代码入口同时生效，并支持登录、切换用户、退出登录后的即时状态切换。

本设计采用用户确认的 C 方案：未登录用户允许执行业务操作，但不能使用管理员功能。

## 2. 角色模型

系统统一使用三个角色：

```text
Unauthenticated = 0
Administrator   = 1
Operator        = 2
```

会话状态包括：

- 当前角色 `CurrentRole`
- 当前用户名 `CurrentUserName`
- 是否已登录由 `CurrentRole <> Unauthenticated` 表示

启动时必须清空用户名并设置为 `Unauthenticated`。退出登录时执行同样的重置。登录成功后，用户名和角色必须来自同一次认证结果，不能通过用户名显示文本推断权限。

## 3. 用户数据格式

用户数据文件新增角色列：

```text
用户名,密码哈希,角色
系统管理员,<hash>,Administrator
操作员,<hash>,Operator
```

兼容旧格式：

- 只有用户名和密码哈希时，“系统管理员”映射为 `Administrator`；
- 其他旧账号映射为 `Operator`；
- 不自动删除或覆盖现有用户数据。

用户管理界面增加角色选择，只允许管理员进入和修改用户角色。禁止操作员创建或修改管理员账号。

## 4. 权限矩阵

| 功能 | 未登录 | 操作员 | 管理员 |
|---|---:|---:|---:|
| 联机测试 | 允许 | 允许 | 允许 |
| 手动测试 | 允许 | 允许 | 允许 |
| NG 复测 | 允许 | 允许 | 允许 |
| 查询统计 | 允许 | 允许 | 允许 |
| 日志查询 | 允许 | 允许 | 允许 |
| 校准 | 允许 | 允许 | 允许 |
| MES 上传 | 允许 | 允许 | 允许 |
| 初始设置 | 禁止 | 禁止 | 允许 |
| 调试 | 禁止 | 禁止 | 允许 |
| 用户管理 | 禁止 | 禁止 | 允许 |

| 退出登录 | 允许 | 允许 | 允许 |

## 5. 权限模块与代码入口

新增集中式权限模块，提供少量稳定接口：

- `GetCurrentRole()`
- `IsAdministrator()`
- `IsAuthenticated()`
- `CanAccess(permission)`
- `ResetSession()`

`MDIForm` 只负责将权限状态映射到菜单和工具栏，不在多个事件中重复判断角色。

以下管理员入口必须同时具备界面禁用和事件级校验：

- 初始设置菜单和工具栏按钮；
- 调试菜单和工具栏按钮；
- 用户管理菜单。

事件级校验失败时不打开窗体，并显示明确提示。这样即使通过快捷键、程序化调用或其他代码路径触发，也不能绕过管理员权限。

业务入口不增加登录拦截，以保持已确认的 C 方案。

## 6. 登录、切换和退出

登录成功后按认证结果更新会话，并立即调用统一的权限刷新方法。

登录菜单支持三种状态：

- 未登录：显示“登录”；
- 已登录：显示“切换用户”和“退出登录”；
- 退出登录后：恢复“未登录”、禁用管理员功能，业务功能保持可用。

状态栏始终显示当前会话用户名；未登录时显示“未登录”，不得显示默认管理员名称。

## 7. 测试与验收

增加权限矩阵和运行时回归检查，至少覆盖：

1. 启动后角色为未登录，管理员功能禁用，状态栏显示“未登录”。
2. 未登录可以执行测试、查询、校准和 MES 上传入口。
3. 操作员登录后管理员功能仍禁用。
4. 管理员登录后管理员功能启用。
5. 退出登录后管理员功能立即禁用。
6. 直接调用管理员事件入口会被拒绝。
7. 新旧两种用户文件格式都能正确加载角色。
8. 用户管理不能让操作员创建或修改管理员账号。
9. 已有 UI 颜色、设备启动和主页面测试回归检查保持通过。

## 8. 非目标与兼容性

- 本次不改变测试流程、设备连接流程或数据库业务逻辑。
- 不删除旧用户数据，不改变密码哈希算法。
- 不将未登录用户限制为只读，因为该行为与已确认的 C 方案冲突。
- 现有设计器文件和主页面布局不因权限改造而重建。
