# 左侧栏 C 方案：暖灰按钮视觉优化设计

## 1. 目标

改善左侧控制栏中普通按钮与白色分组背景融为一体的问题，使按钮边界、可点击性和操作层级更清晰，同时保持现有 OCV 测试功能、256 通道逻辑、数据库流程和控件布局不变。

本设计基于用户确认的 C 方案：普通按钮使用暖灰底色，并通过较明确的边框和按下/悬停状态形成轻微实体按钮感。

## 2. 范围

纳入本次视觉调整的控件：

- 普通 `Button` 控件，即 `UiTheme.ButtonRole.Neutral`。
- 危险 `Button` 控件，即 `UiTheme.ButtonRole.Danger`；它不再使用纯白背景，而使用现有的浅红语义背景。
- 未选中的 `RadioButton` 和 `CheckBox`，包括自动/手动、通道选择等按钮化选项。
- 上述控件的默认、悬停、按下和禁用状态。

明确不改变：

- 蓝色主操作按钮的语义和行为。
- 红色停止/报警按钮、橙色 NG 按钮、绿色运行状态的语义色。
- 文本框、数值输入框和日志区域的白色输入背景。
- 控件事件、测试流程、数据通信、数据库和 MES 逻辑。
- 左侧栏现有布局、控件位置和尺寸，除非状态反馈需要使用已有的控件属性。

## 3. 视觉令牌

| 用途 | 颜色/表现 |
| --- | --- |
| 普通按钮背景 | `#E7E7E5` |
| 普通按钮边框 | `#A7ADB5` |
| 普通按钮文字 | 继续使用 `UiTheme.TextPrimary` |
| 普通按钮悬停 | 在暖灰基础上加深一档，建议 `#DEDFDD` |
| 普通按钮按下 | 在暖灰基础上加深并保持边框，建议 `#D4D6D3` |
| 普通按钮禁用 | 使用低对比度暖灰和次级文字色，仍保留边界 |
| 危险按钮背景 | 继续使用现有 `DangerBackground`（`#FFE0DE`），避免纯白按钮面 |
| 选中态 | 保持现有 `UiTheme.Primary` 蓝色和白色文字 |
| 主操作/危险/警告/成功 | 保持现有角色色，不套用普通按钮暖灰底 |

WinForms 标准 `Button` 不额外绘制投影层；“轻微下压阴影”通过边框、悬停背景和按下背景的层次实现，避免引入自定义绘制造成 DPI 或主题兼容问题。

## 4. 样式应用规则

### 4.1 普通 Button

调整 `UiTheme.ApplyButtonStyle` 的 `ButtonRole.Neutral` 分支：

- 背景改为普通按钮暖灰色。
- 边框改为 `#A7ADB5`。
- 增加统一的 `MouseOverBackColor` 和 `MouseDownBackColor`。
- 保持字体、文字颜色、平面按钮风格和现有事件不变。

### 4.2 未选中的 RadioButton/CheckBox

调整 `UiTheme.ApplyToggleStateStyle` 的未选中分支：

- 背景改为普通按钮暖灰色。
- 边框改为普通按钮边框色。
- 选中分支保持蓝色主色，以保证当前模式/当前选择能被快速识别。
- 如果控件支持悬停/按下背景，使用与普通 Button 相同的色阶。

### 4.3 有语义的按钮

`Primary`、`Warning` 以及运行状态控件继续使用各自角色色。`Danger` 保持红色文字和边框，并将背景设为现有 `DangerBackground` 浅红色；它不使用暖灰背景，也不再使用纯白背景。

## 5. 验收标准

1. 左侧栏中所有普通按钮和危险按钮不再使用纯白背景。
2. 普通按钮与白色分组背景之间能清晰看到独立边界。
3. 自动/手动等未选中选项与普通按钮具有一致的暖灰风格。
4. 当前选中项仍能通过蓝色背景明确识别。
5. 启动测试、停止测试、NG 点测试和运行状态的颜色语义不被削弱；停止/危险按钮使用浅红底保持危险提示。
6. 文本框仍保持白色，用户能区分“可输入区域”和“可点击按钮”。
7. 鼠标悬停、按下、禁用状态均有可感知但不过度的明暗变化。
8. 不引入业务逻辑变化，现有项目能够正常编译。

## 6. 验证方式

- 对 `UiTheme` 的样式分支进行静态检查，确认角色色未被普通按钮色覆盖。
- 构建 `XL-OCV-UIControls.vbproj`，确认 VB.NET 语法和引用正常。
- 启动可运行程序后检查左侧栏：普通按钮、选中按钮、主操作、危险操作、警告状态、文本框和禁用状态。
- 在非默认 DPI 或窗口缩放下确认按钮文字和边框没有裁切。

## 7. 非目标

本次不重新设计顶部导航、256 通道矩阵、日志区域、窗口整体布局或业务流程；这些内容属于后续独立 UI 迭代。
