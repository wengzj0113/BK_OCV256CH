# 左侧栏深石板按钮视觉优化设计

## 目标

解决截图中左侧操作按钮仍然接近白色、按钮边界不明显的问题。采用用户确认的 C 方案，将普通按钮统一为深石板灰，并补齐当前未经过 UiTheme 的左侧按钮样式调用。

## 根因

- `UiTheme` 当前普通按钮背景为 `#E7E7E5`，亮度仍接近白色。
- `frmTest.Designer.vb` 为控制板、通道选择和报警复位按钮写入了白色默认背景。
- `frmTest.vb:SetSelectionModeButton` 在通道选择状态刷新时直接恢复 `CardBackground`，绕过统一主题。
- 只有测试模式和工位选择控件调用了 `ApplyToggleStateStyle`，其他左侧按钮没有运行时统一初始化。

## 视觉规则

| 控件状态 | 颜色 |
| --- | --- |
| 普通按钮背景 | `#C1C8D2` |
| 普通按钮边框 | `#5D6B7A` |
| 普通按钮悬停 | `#B4BCC7` |
| 普通按钮按下 | `#A6B0BC` |
| 危险按钮背景 | `DangerBackground` `#FFE0DE` |
| 主按钮/选中项 | 继续使用 `Primary` `#1769E8` |
| 警告按钮 | 继续使用 `Warning` `#F3A400` |
| 输入框 | 继续使用白色 `CardBackground` |

普通按钮采用深石板灰以提高远距离和强光环境下的辨识度。危险、主操作和警告按钮保留语义色，不被普通灰覆盖。

## 实现范围

1. 在 `UiTheme.vb` 中替换普通按钮背景、边框、悬停和按下令牌。
2. 保持 `Danger` 使用浅红底，避免纯白危险按钮。
3. 在 `frmTest.vb` 增加左侧按钮统一初始化：获取条码/启动测试使用主色，停止测试/报警复位使用危险色，NG 点测试使用警告色，托盘和通道操作使用普通色。
4. 将 `SetSelectionModeButton` 的非激活分支改为普通深石板样式，并保留激活按钮蓝色。
5. 不修改 Designer 中的输入框、分组背景、日志和状态指示灯颜色；运行时主题初始化覆盖按钮的 Designer 默认值。

## 验收标准

- `手动、开启托盘、闭合托盘、全选、清除、框选、单选、报警复位` 等普通/危险按钮不再显示纯白按钮面。
- `启动测试` 和当前选中项为蓝色，`停止测试/报警复位` 为浅红色，`NG点测试` 为橙色。
- 普通按钮与白色分组背景之间有明显边界，悬停/按下有明暗反馈。
- 文本框仍为白色。
- 不改变任何按钮事件、测试流程、设备通信、数据库或 256 通道选择逻辑。
- UI 控件项目构建成功，运行时样式冒烟检查通过。
