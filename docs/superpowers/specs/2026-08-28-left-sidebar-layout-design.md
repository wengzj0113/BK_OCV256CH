# frmTest 左侧控制栏布局设计

## 目标

在不改变现有测试、通讯、数据库、MES 和按钮事件业务的前提下，按照现场参考图重排 `frmTest` 左侧控制栏：保留纵向业务顺序，收紧上下空间，补齐 OCV0/OCV1/OCV2 工作站显示，增加可见的自动/手动测试控制，并保证窗体每次首次打开时左栏从顶部开始显示。

## 当前基线

- 项目为 VB.NET WinForms，主窗体为 `frmTest`。
- 左侧由 `Panel1` 承载多个固定坐标 `GroupBox`，当前控件顺序为工作站、控制板、通道选择、合格范围、报警、探针、日志和报警复位。
- `ResponsiveTestLayout` 会把左侧控件放入可滚动内容面板，但内容内部仍依赖 Designer 的 `Location/Size`，因此组间距和隐藏控件会造成纵向空白。
- `frmInit` 已保存 `stationSelect = 0/1/2`，并已有 OCV0/OCV1/OCV2 设置项；`frmTest` 运行时仍只显示 OCV1/OCV2，且 OCV3 控件默认隐藏。
- 当前工作区存在其他业务改动，本设计只覆盖 `frmTest.Designer.vb`、`frmTest.vb`、`ResponsiveTestLayout.vb`、`UiTheme.vb` 以及必要的 UI 验证脚本。

## 设计方案

### 左栏结构

左栏保持现场熟悉的顺序，但统一由一个垂直布局容器管理，避免依赖各 GroupBox 的绝对坐标：

1. 测试控制：自动、手动两个可见复选框。
2. 工作站选择：OCV0、OCV1、OCV2 三个互斥选项。
3. 控制板：托盘码、待测试通道数、启动测试、停止测试、NG 点测试、托盘状态、开启托盘、闭合托盘。
4. 通道选择：全选、清除、框选、单选四个按钮同一行。
5. 合格范围设置：电压和内阻使用 Min/Max 三列网格。
6. 报警指示：四个温度值两列排列，烟感和设备状态在底部一行。
7. 探针使用次数统计。
8. 事件日志。
9. 报警复位。

每个区块统一使用 5~6px 外间距、6~8px 内边距；按钮和输入框使用统一高度。低频信息不额外引入复杂折叠，以保持参考图的操作路径。

### 测试模式

新增 `chkAutoTest` 和 `chkManualTest` 两个 `CheckBox`，放在左栏首部，默认自动模式。两个控件允许用户点击，但通过统一的模式切换处理保持互斥；自动模式允许现有 PLC/夹具自动启动逻辑生效，手动模式只允许用户通过启动按钮开始测试。现有 `autoStartFlag` 仍作为硬件信号状态来源，不改动通讯解析。

### 工作站

`Rbtn1/Rbtn2/Rbtn3` 在 `frmTest` 中显示为 OCV0/OCV1/OCV2，并根据 `Initsetting.stationSelect` 选择默认项：0→OCV0、1→OCV1、2→OCV2。保留控件名称和既有按钮/测试入口，避免扩大到数据库字段和历史 CSV 迁移；当前测试流程继续沿用现有内部阶段编号，除非编译或回归证明必须同步修改业务映射。

### 启动滚动位置

增加一个明确的左栏滚动复位入口，在首次布局完成、窗体 Load 的异步布局稳定之后执行一次 `AutoScrollPosition = New Point(0, 0)`。窗口 Resize 只重新计算布局，不反复抢占用户已经滚动到的位置。

## 文件边界

- `frmTest.Designer.vb`：声明和初始化两个模式 CheckBox，重新组织左栏控件布局和尺寸，显示 OCV0/1/2，通道选择四按钮一行。
- `frmTest.vb`：初始化模式和工作站，处理模式互斥，保留现有事件，调用一次启动滚动复位。
- `ResponsiveTestLayout.vb`：将左栏内容布局从固定坐标堆叠改为紧凑垂直布局，并提供不改变用户滚动位置的重排路径。
- `UiTheme.vb`：集中定义左栏间距、按钮高度和 CheckBox/RadioButton 的显示样式。
- `tools/Test-ChannelGridFit.ps1` 或新增同类脚本：验证关键控件存在、工作站文本、四按钮同一行及滚动复位代码路径。

## 业务保护

- 不删除现有业务控件，不改动 `btnStart_Click`、`btnStop_Click`、`btnNGTest_Click`、托盘按钮、通道选择按钮的事件绑定。
- 不修改 PLC、中位机、34461A、3562A、数据库或 MES 通讯实现。
- 模式控件只控制自动启动入口和显示状态，不绕过报警、运行中和通信检查。
- 不在高频测试更新中调用整个窗体刷新。

## 验收标准

- 工作站选择区域可见 OCV0、OCV1、OCV2，默认项与 `Initsetting.stationSelect` 一致。
- 自动、手动两个复选框在左栏顶部可见，任意时刻最多一个选中。
- 通道选择四个按钮在同一行，无重叠或换行。
- 左栏顺序与参考图一致，组间距统一，首屏显示模式、工作站、控制板和通道选择，纵向空白明显减少。
- 窗体首次启动和布局稳定后，左栏滚动位置为顶部；用户后续手动滚动不因普通 Resize 被强制复位。
- 项目 Debug x86 编译成功，现有 UI 回归脚本和新增静态检查通过。
