# XL-OCV-256CH 绿色压缩包与 HTML 使用说明书设计

## 目标

为 XL-OCV-256CH Windows 桌面程序生成一个可复制到其他电脑、解压后直接运行的绿色压缩包。压缩包同时提供一份离线可打开的中文 HTML 使用说明书，并提供可重复执行的自动打包脚本。

## 已确认的方案

采用绿色压缩包，不制作 Setup 安装程序，不修改现有业务代码。程序默认解压到用户有写权限的目录，例如 `C:\XL-OCV-256CH`，以兼容程序当前把配置文件和日志保存到程序目录的行为。

## 项目现状与边界

- 主程序为 VB.NET Windows Forms 应用，目标框架为 .NET Framework 4.8。
- 主程序当前按 x86 目标编译，目标电脑可以是 Windows 10/11 64 位系统。
- 构建输出包含主程序、项目引用的 DLL、配置文件和清单文件；调试符号与 XML 文档不属于运行时必需文件。
- 程序使用 Keysight/NI VISA 的 COM 互操作组件访问仪器；该驱动属于外部运行环境，不随项目 DLL 自动获得。
- 程序使用 Microsoft Office Interop 执行 Excel 导出；相关功能需要目标电脑安装兼容的 Microsoft Office。
- 程序会在自身目录使用 `Initset.set`、`bar.set` 和 `logFile` 等运行数据，因此不默认放入受 UAC 保护的 `Program Files` 目录。

## 交付物

在 `dist` 目录生成：

```text
XL-OCV-256CH-Portable.zip
```

压缩包解压后包含：

```text
XL-OCV-256CH\
├─ XL_OCV_256CH.exe
├─ XL_OCV_256CH.exe.config
├─ XL_OCV_256CH.exe.manifest（若构建输出提供）
├─ XL_OCV_UIControls.dll
├─ 其他运行时必需 DLL
├─ 运行所需的 CSV/SET/资源文件
├─ 使用说明书.html
└─ 运行说明.txt
```

打包以 Release|x86 构建输出为来源，自动收集运行时文件，不把 `.pdb`、XML 文档、临时发布目录或构建验证目录放入最终绿色包。

## 自动打包脚本

新增 PowerShell 脚本 `tools\Build-PortablePackage.ps1`，职责为：

1. 定位项目和可用的 MSBuild。
2. 以 Release|x86 编译主项目及其项目引用。
3. 清理并重建一个明确的临时 staging 目录。
4. 复制运行时必需文件、数据模板和 HTML/文本说明书。
5. 对 staging 目录执行基本完整性检查，确认主 exe、配置文件和说明书存在。
6. 生成 `dist\XL-OCV-256CH-Portable.zip`，并输出包路径、文件数量和大小。

脚本不删除用户源码、现有构建验证目录或当前工作区中的其他文件；只会覆盖脚本管理的 staging 和 dist 产物。

## HTML 使用说明书

新增离线单文件 `使用说明书.html`，使用内嵌 CSS，不依赖网络资源。内容按现场操作顺序组织：

- 适用版本、系统要求和外部依赖
- 解压位置与程序启动
- 登录、角色和权限
- 初始设置及配置保存
- 串口、PLC、中间机和仪器连接
- 手动测试与正式测试的基本流程
- 通道校准
- 数据保存、查询和 Excel 导出
- 日志查看与问题定位
- 常见启动、串口、VISA、数据库和 Excel 问题
- 数据备份与绿色包迁移建议

说明书应明确区分“程序本身包含的文件”和“必须由现场另外安装或配置的 VISA、Office、设备驱动、数据库/网络服务”，避免让使用者误以为绿色包已经包含这些外部环境。

## 错误处理与兼容性

- 目标电脑未安装 .NET Framework 4.8 时，运行说明书给出安装要求和处理方法；本次绿色包不静默修改系统组件。
- 缺少 VISA 时，程序基础界面仍可启动，但仪器通信功能可能不可用；说明书提供检查与安装提示。
- 未安装 Office 时，主程序基础功能仍可使用，但 Excel 导出功能不可用；说明书明确说明这一点。
- 绿色包不负责安装硬件驱动、注册 COM 组件、创建数据库服务或修改系统环境变量。
- 文件路径和压缩包目录名使用稳定的英文目录名，说明书内容使用中文。

## 验证与验收标准

制作完成前执行以下验证：

- Release|x86 构建命令退出码为 0。
- staging 目录中主程序、配置文件、项目 DLL 和 `使用说明书.html` 均存在。
- 压缩包可以正常列出并解压，文件数量与 staging 一致。
- HTML 文件可被浏览器打开，编码、标题、目录和主要章节完整。
- 从绿色包目录启动主程序，至少完成进程启动级验证；不在没有真实仪器、VISA、Office 和现场数据库的环境中虚报设备联机验证结果。
- 最终交付时列出已验证项目和仍需在目标电脑现场确认的外部依赖。

## 非目标

- 不改变程序业务逻辑、权限逻辑或设备通信协议。
- 不把专有 VISA 驱动、Microsoft Office 或硬件驱动复制进项目包。
- 不制作 MSI/Setup.exe，不增加自动更新机制。
- 不把当前工作区已有的临时构建目录和调试产物作为发布内容。
