# 校准页面表头中文化设计

## 目标

把通道校准页面表格中显示为 `DataGridView...Column...` 的默认控件名称替换为能直接说明字段含义的中文表头。只调整表头文本，不改变校准、计算、保存或读取行为。

## 表格列

列顺序保持现状，表头如下：

| 列 | 表头 | 含义 |
|---|---|---|
| 1 | 选择 | 勾选需要校准的通道 |
| 2 | 通道号 | 1 至 256 的通道编号 |
| 3 | 当前补偿值（mΩ） | 当前已保存并供正式测试使用的通道补偿值；允许在表格中编辑 |
| 4 | 实测电阻（mΩ） | 本次校准从电阻表读取的测量值 |
| 5 | 标准电阻（mΩ） | 本次校准使用的标准电阻值，与页面顶部输入值一致 |
| 6 | 本次补偿值（mΩ） | 本次计算得到的补偿值，等于标准电阻减去实测电阻 |
| 7 | 校准时间 | 本次校准执行时间 |
| 8 | 校准状态 | 未校准、校准中、校准成功或失败信息 |

## 行为与数据流

- 页面加载时，当前补偿值仍从既有校准数据加载。
- 单通道或批量校准仍按“标准电阻 − 实测电阻”计算本次补偿值；成功后继续更新当前补偿值。
- 校准时间、状态、编辑和保存逻辑均保持不变。
- 不修改 CSV/数据库格式、字段名、计算公式、列顺序或列宽策略。

## 验收标准

- 页面展示以上 8 个中文表头，且单位明确。
- 每个表头均对应正确的数据列；当前补偿值与本次补偿值含义可区分。
- 校准和数据持久化逻辑不因本次文案调整而改变。
