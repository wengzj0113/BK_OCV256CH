# 主界面事件日志最新记录置顶设计

## 目标

主测试界面的“事件日志”始终将最新一条记录显示在最上方，便于操作员快速查看刚发生的流程事件。

## 设计

- 继续使用现有多行 `txtAlarm` 文本框，不调整布局。
- 插入新记录时放到文本框开头，并将光标/视图定位到开头。
- 主界面事件日志保留控件当前的 32,767 字符容量；超出时从文本框末尾删除最旧的完整日志行。
- 每轮测试开始时仍清空主界面事件日志。
- 自动流程日志文件仍按发生顺序追加，保留完整历史；界面显示顺序不改变文件内容。
- 待写队列容量仅限制尚未写入磁盘的排队记录，不作为历史记录保留上限。

## 验收标准

- 新事件出现在事件日志框的第一行，且视图显示第一行。
- 达到界面容量后，添加新事件不会丢失新记录；末尾只移除最旧的完整行。
- 自动流程日志文件仍按时间先后顺序追加，不受界面排序影响。
- 新一轮测试开始后界面日志仍会清空。
