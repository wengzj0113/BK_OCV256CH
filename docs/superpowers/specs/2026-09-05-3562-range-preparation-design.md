# 3562 测试前远程设置 300 mΩ 量程设计

## 目标

每次正式测试开始前，通过串口远程关闭自动量程并设置 HIOKI 3561/3562 内阻仪为 300 mΩ 量程，确保主页面和手动测试使用一致的量程准备流程。

## 约束

- 仪表返回的真实 0 值和负值继续保留，不在解析、映射或显示层截断或改判。
- 不改变通道选择、缓存记录顺序、PLC 生命周期和结果单位换算。
- 量程设置必须发生在清空缓存之前；仪表手册说明改变量程会清除存储数据。

## 实施方案

在 `PrepareCachedData_3562` 中，每次测试都按以下顺序发送命令：

1. `:AUT OFF`，关闭自动量程；
2. `:RES:RANG 300E-3`，选择 300 mΩ 量程；
3. 设置外部触发和连续初始化；
4. 清空并开启仪表内存缓存。

成功发送后记录目标量程；异常时保留现有失败返回路径并记录异常信息。由于该函数每次正式测试都会调用，量程不会依赖启动时的静态初始化状态。

## 验证

- 源码回归测试验证 `:AUT OFF` 和 `:RES:RANG 300E-3` 位于 `MEMory:CLEA` 之前；
- 测试验证保留 0 与负值的缓存解析结果；
- x86 Debug 解决方案重建；
- 运行 3562 缓存解析、主页面测试生命周期和通道选择回归测试。
