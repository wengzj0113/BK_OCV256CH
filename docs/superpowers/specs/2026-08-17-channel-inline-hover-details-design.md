# 通道悬浮详情内嵌布局设计

## 目标

把通道格子的动态详情从屏幕级 ToolTip 移到 `ChannelGridControl` 标题行右侧，避免统计区右上角溢出和被窗口裁剪。

## 设计

- `ChannelTileControl` 不再使用屏幕级 `ToolTip.Show`。
- 通道格子在鼠标进入时发布包含 `ChannelDisplayData` 的悬浮事件，离开时发布清除事件。
- `ChannelGridControl` 在标题行中增加动态详情 Label，接收悬浮事件并显示完整格式化信息。
- 标题行采用两列布局：左侧固定标题，右侧占剩余空间；详情 Label 使用省略号和自动换行保护布局。
- 鼠标离开通道网格后清除详情，避免显示过期通道信息。

## 验收标准

1. 悬浮第 13～16 列时，详情显示在标题行右侧，不出现在统计区右上角。
2. 详情文本不会超出 `ChannelGridControl` 右边界。
3. 鼠标离开格子后详情被清除。
4. 现有通道点击事件和通道状态刷新保持不变。
5. 项目 Debug/x86 和解决方案 Any CPU 映射配置均可 Rebuild。
