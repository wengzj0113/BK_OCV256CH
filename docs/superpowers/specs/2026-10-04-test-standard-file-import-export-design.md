# 参数页测试标准文件导入与保存设计

## 目标

在 `frmInit` 的“参数设置”页，为现有内阻、电压上下限配置增加“导入标准”和“保存标准”两个操作。标准以 UTF-8 文本 `.set` 文件保存到应用目录下的 `SETS` 文件夹；导入值回填到当前设置窗体，只有点击“确定”后才应用。

## 当前上下文

- `frmInit.Designer.vb` 中 `TabPage2` 是“参数设置”，`GroupBox6` 包含内阻、电压上下限输入框 `txtRes1/txtRes2/txtVol1/txtVol2`。
- `frmInit.vb` 在点击“确定”时把四个文本框转换到 `TempInitsetting`，随后沿用现有应用流程。
- 应用当前用 `Application.StartupPath\Initset.set` 存取整份初始化配置。该文件由 `BinaryWriter` 写入，是二进制格式，不能用于本功能的文本标准文件。
- 初始化设置入口已有管理员权限校验；新按钮继承相同的访问范围。
- 上下限配置位于共享 `Initsetting`，因此导入并应用的当前标准同时用于自动和手动测试。

## 用户流程

### 保存标准

1. 用户在“参数设置”页填写内阻和电压下限、上限。
2. 点击“保存标准”，显示保存文件对话框，初始目录为 `<应用目录>\SETS`，扩展名固定为 `.set`。
3. 文件名即标准名称。保存前验证四个值均为当前区域设置下可解析的非负数，且各自最小值不大于最大值。
4. 同名文件由保存对话框提示覆盖；文件写入使用临时文件再替换，避免中断时留下半份标准。
5. 保存仅写入标准文件，不提交其它初始化参数，也不改变当前测试配置。

### 导入标准

1. 点击“导入标准”，显示打开文件对话框，初始目录为 `<应用目录>\SETS`，默认筛选 `.set`；用户仍可从其它位置选取标准文件。
2. 完整读取并验证文件格式、版本和四个数值，校验全部通过后才一次性回填四个输入框。
3. 文件错误或范围无效时显示可理解的提示，保留导入前的四个输入值。
4. 导入只回填窗体编辑值；点击“确定”才由当前设置保存流程应用，点击“取消”则丢弃。
5. 用户编辑导入值后，以相同文件名保存会覆盖原标准（系统确认覆盖）；使用新文件名保存一个新的标准文件，保留原文件。

## 文件格式

采用 UTF-8（无 BOM）纯文本，使用固定键名与不受系统区域设置影响的小数点格式：

```ini
Format=XL-OCV-TestStandard
Version=1
ResistanceMinMilliOhm=0
ResistanceMaxMilliOhm=0
VoltageMinMilliVolt=0
VoltageMaxMilliVolt=0
```

解析器要求格式标识、版本、四个唯一键全部存在；拒绝未知版本、重复键、缺失键、非法数字、负数以及下限大于上限。应用目录中的旧 `Initset.set` 路径与布局保持不变；本功能的文件仅出现在 `SETS\<文件名>.set`。

## 技术结构

- 新增 `TestStandardProfile.vb`，定义不可变边界清晰的 `TestStandardProfile` 数值模型及 `TestStandardFileStore`。模型负责范围校验；文件服务负责 `SETS` 目录、文本编码、键值解析和原子写入。读取方法允许外部 `.set` 路径，以支持导入。
- `frmInit.Designer.vb` 仅增加两个可视化设计按钮并调整 `GroupBox6` 布局，使量程区域和右侧按钮在同一容器内。所有新增/移动的控件通过 Designer 序列化，`frmInit.vb` 不在运行时创建控件。
- `frmInit.vb` 仅负责对话框配置、从控件读取/回填值和用户提示。按钮事件不直接修改全局 `Initsetting`，最终应用仍走原有“确定”逻辑。
- 在 `MP-60A-RV-64Mem.vbproj` 显式登记新增 VB 文件，保持旧式 VB 项目文件的编译清单一致。
- `SETS` 文件夹不存在时由文件服务创建。若应用目录无写权限，保存失败时展示明确错误并保留表单状态，不静默转存到其它路径。

## 验证

- 构建 WinForms 项目，确认 Designer 与 VB 编译通过。
- 用运行时验证脚本覆盖：创建 `SETS`、往返读写、文件名扩展处理、覆盖保护、区域设置无关的小数格式、非法/缺失/重复键、负数、上下限倒置、读取损坏文件不产生部分结果。
- 用静态回归脚本确认控件定义在 `frmInit.Designer.vb`，项目包含新文件，按钮仅回填文本框且初始设置确定/取消路径未被旁路。
- 不连接 PLC、仪表或生产数据库；该功能只读写本地标准文件。
