# NG 复测页面并列对照方案

日期：2026-10-11

## 目标

优化 NG 复测页面，让操作员扫码后能立即核对电池原始 NG 数据与复测数据，并在明确勾选覆盖时自动把复测结果写回该电池对应的原始测试记录。无 NG 历史记录时，调试模式允许采集并显示仪表结果，但不得写入数据库。

## 当前行为与问题

- `FrmNgRetest` 当前只在回车或点击“查询”后查询条码；查询成功后把来源、判定、电压、内阻和托盘位置合并显示在一个文本区域。
- 查询使用 `dbo.usp_GetNgRetestSourceByBatteryCode`，只返回正式 NG 记录；查无记录会抛出“未找到该电池的NG历史记录”，并禁用复测。
- 查询过程没有把 `TestResultId` 传给应用层。覆盖保存过程按条码重新找最新 `TestResult`，存在更新到另一条同条码记录的可能，不能保证命中查询时显示的托盘/通道来源。
- 复测数据目前始终写入 `OCV_RETEST_DATA`；勾选覆盖后还会额外弹出确认框，再更新原始测试数据。

## 页面方案：并列对照

页面主体分为左右两个数据卡片：

| 历史 NG | 本次复测 |
| --- | --- |
| 原始判定、历史电压、历史内阻、测试时间 | 复测判定、复测电压、复测内阻、采集时间 |

条码、托盘号、通道号/托盘位置以及 3562 连接状态显示在卡片上方。没有历史记录时，左侧保留空状态提示；复测值在采集前显示待测状态。数值与单位清晰区分：电压 mV，内阻 mΩ。复测判定 OK/NG 用颜色辅助识别，不单独依赖颜色表达状态。

页面保留扫码输入框和手动“查询”按钮。扫码枪发送回车时自动查询；手动查询仍可用于键盘输入。每次换条码后清空上一次复测值、恢复“覆盖历史”未勾选，并重新查询。

## 操作与保存规则

### 查询和正式复测

1. 扫码回车或点击“查询”后，按条码查找正式 NG 历史，并同时取得来源记录的 `TestResultId`、托盘号、通道号/位置、历史电压/内阻、判定和时间。
2. 查到来源后启用“复测”。点击后从 3562 采集电压和内阻，在右侧显示本次结果。
3. “覆盖历史”默认不勾选。未勾选时，保持历史 `TestResult` 不变，并按当前行为把复测数据写入 `OCV_RETEST_DATA` 作为复测审计记录。
4. 勾选后，测量完成即自动保存复测审计记录并更新查询时取得的**同一条 `TestResultId`**；不再弹二次确认。若更新目标已不存在或不再满足可覆盖条件，整个保存事务失败并提示，不得静默只写入审计记录。
5. 写入审计记录时同时保留 `SourceTestResultId`，便于追溯本次复测针对的来源。数据库脚本为已有表添加可空列，旧记录继续可读。

### 无历史记录与调试模式

- 查询到“无正式 NG 历史”时，历史卡片显示“无 NG 历史记录”，默认禁用复测。
- 提供默认关闭的“调试模式”选项；仅当查询明确返回无历史时，操作员打开它才启用复测。
- 调试采集结果显示在右侧并标记“仅显示，未入库”。无论“覆盖历史”控件状态如何，调试结果均不写 `TestResult`、`OCV_RETEST_DATA` 或其他业务数据表；覆盖选项在此状态禁用。
- 数据库连接、超时或查询异常必须显示为查询错误，不能当作“无历史”处理，也不能借调试模式绕过。
- 新条码开始查询时关闭调试模式，避免误把上一条码的状态带入新条码。

## 数据与模块边界

- `FrmNgRetest` 管理界面状态与流程：查询中、无历史、正式 NG 来源、调试可测、采集中、已采集、保存失败/成功。
- `NgRetestDataService` 负责返回来源记录及精确来源 ID，并按正式/调试路径执行保存。调试路径不调用保存方法。
- 查询存储过程返回 `TestResultId`。保存存储过程接收该 ID，覆盖时只更新该 ID，并检查实际更新行数；不要再用条码取最新记录。
- `OCV_RETEST_DATA` 增加可空 `SourceTestResultId`，新正式复测记录保存来源 ID。历史数据无需回填。
- 仪表采集服务继续只负责测量和判定；它不决定是否保存或覆盖。

## 状态与错误处理

- 查无历史与系统查询失败使用不同提示和状态。调试模式只对前者生效。
- 测量失败时保留历史卡片，右侧显示采集错误，不执行任何保存。
- 正式保存成功后显示“已记录复测”以及是否已覆盖；保存失败时保留测量值并明确提示未保存，允许操作员重试保存时避免重复采集（实现时需沿用现有保存流程并防止重复插入）。
- 忙碌期间禁止切换条码、查询和再次复测，避免结果写入错误条码。

## 验收标准

- 扫码回车后自动查询，页面左右分别显示历史电压/内阻与复测电压/内阻，并显示来源托盘和位置。
- 新条码、页面初始化时“覆盖历史”均为未勾选。
- 未勾选覆盖时只记录复测审计，不改原始测试数据；勾选后无额外确认，更新的记录 ID 与查询展示来源一致。
- 无历史时，调试模式关闭则不能复测；开启后可以采集并显示，数据库业务表无任何新增/更新。
- 数据库错误不会触发调试放行；仪表失败或保存失败有清晰状态反馈。

## 不在本次范围

- 修改正式测试、自动测试或 PLC 流程。
- 改变仪表通信协议、NG 判定阈值或复测结果的计算方式。
- 调试采集数据的导出、打印或持久化。
