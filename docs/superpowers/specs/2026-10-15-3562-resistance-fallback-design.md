# 主页面 3562 内阻异常替代值规则

2026-10-15 用户确认：内阻异常大、没有数据、记录不足或解析失败时，使用 **10000 mΩ**，避免异常科学计数值在 @Results 入库时溢出。规则用于共同测量执行器，覆盖主页面自动、手动及其 NG 复测。

## 行为

- 换算为 mΩ 后绝对值达到 10000，或为 NaN/Infinity，替换为正的 10000。
- 数量、序号和顺序可靠时，单条格式/数值异常仅替代对应位置，不跳过记录。
- 缓存为空、条数与计划不符、序号无效或不连续时，整批替代，输出长度严格等于读取计划。禁止猜测缺失位置导致后续通道错位。
- 串口读取异常时保留错误日志，并生成本批数量的 10000 内阻结果。无效计划（expectedCount <= 0）仍失败。
- 单组双遍保持完整计划长度，执行器仍取第二遍；缺记录时整批替代，避免遍次错位。
- 替代值始终判为内阻 NG，即使配置的内阻上限大于 10000。
- 替代值跳过校准补偿：Resistance、RawResistanceMilliohm、FinalResistanceMilliohm 均为 10000，实际施加的 CalibrationValueMilliohm 为 0。正常内阻继续按校准快照补偿。
- 电压由 34461 独立读取；其读取失败仍走既有失败路径，不使用缺失的 3562 电压占位值。
- 采集日志记录有效、异常和替代条数，以及整批替代原因。正常后处理继续由共同周期执行；无需扩充数据库字段。

## 改动文件

`InstrumentCacheParser.vb` 定义常量、数值归一化和记录替代；`Module1.vb` 处理读取异常替代、日志和 NG 判定；`TwoPassResultMapper.vb` 保证显示与保存字段一致，并跳过替代值补偿。
