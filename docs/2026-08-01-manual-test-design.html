手动测试功能设计文档

项目：XL_OCV_256CH；日期：2026-08-01；目标窗体：MDI 主界面新增“手动测试”。

1. 功能定位

手动测试定位为设备调试和通道验证工具，不作为正式生产测试入口。它允许操作员手动选择 1~256 中任意通道， 启动一次中位机通道计划和仪表缓存读取，并在独立页面显示本次结果。

第一版不写正式数据库、不上传 MES、不保存正式生产 CSV、不触发 NG 复测、不增加探针寿命计数、不执行夹具动作。

2. 菜单与打开方式

在 MDI 主窗体菜单“测试(&T)”下新增“手动测试”。点击后打开独立窗体 FrmManualTest。

Using frm As New FrmManualTest()
    frm.ShowDialog(Me)
End Using

使用 ShowDialog(Me) 模态显示，保证窗体限制在 MDIForm 顶层，用户关闭手动测试页之前不能操作主窗体。

3. 页面布局

3.1 顶部操作区

  • 全选
  • 清空
  • 反选
  • G1 全选
  • G2 全选
  • 起始通道输入框
  • 结束通道输入框
  • 添加范围
  • 零星通道文本框
  • 添加列表

3.2 通道矩阵

中间区域显示 16 行 x 16 列通道矩阵，共 256 个通道。

区域通道显示建议
G1CH1~CH128浅蓝或浅灰背景，选中后高亮。
G2CH129~CH256浅绿或浅灰背景，选中后高亮。

每个控件显示物理通道号，例如 CH151。鼠标提示可显示 G2 本地 CH23。

3.3 状态与结果区

  • 已选总数
  • G1 已选数量
  • G2 已选数量
  • 预计 3562 触发次数
  • 预计 34461 触发次数
  • 状态文本：空闲、测试中、测试完成、测试失败
  • 结果表格：通道、分组、电压 mV、内阻 mΩ、判定

4. 通道选择规则

页面只接收物理通道号：1~256。

输入方式规则
单个点击点击通道按钮，在选中和取消之间切换。
范围添加起始和结束必须是 1~256 的整数，起始不能大于结束。
列表添加支持 3,8,25,129、3，8，25，129、CH3、CH8、CH25、CH129。
去重排序页面层去重，底层 TestChannelPlanService 也会再次去重排序。

非法输入应提示具体无效项，例如：以下通道无效：0,257,abc。

5. 测试启动流程

  1. 用户选择通道。
  2. 点击“开始测试”。
  3. 检查是否选择至少一个通道。
  4. 检查 isRuning，如果系统正在测试则禁止启动。
  5. 检查中位机串口通讯 CheckCom_SCM()。
  6. 设置 isRuning = True，禁用页面操作按钮。
  7. 调用 FormalTestRunner.RunSparseMeasurement(channelNumbers)。
  8. 从 RecieveData 读取本次选中通道结果。
  9. 显示电压、内阻和 OK/NG 判定。
  10. 写入手动测试日志。
  11. 恢复按钮，设置 isRuning = False。
Dim channelNumbers As List(Of Integer) = GetSelectedChannels()
Dim formalRunner As New FormalTestRunner()
formalRunner.RunSparseMeasurement(channelNumbers)

6. 复用和不复用的模块

模块是否复用说明
FormalTestRunner复用负责清缓存、设置仪表、下发中位机计划、读取缓存、回填数据。
TestChannelPlanService复用负责通道去重排序、G1/G2 拆分、G2 本地通道转换。
TwoPassResultMapper复用负责按两遍模式将内阻和电压回填到 RecieveData。
StarTest不复用它包含托盘号、夹具、MES、数据库、探针寿命、NG 复测等生产流程，不适合作为手动测试入口。

7. 日志设计

手动测试不写正式 CSV，但写调试日志：

logFile/ManualTest_yyyyMMdd.log

日志内容包括：

  • 开始时间、结束时间
  • 选择通道列表
  • G1/G2 拆分数量
  • 执行成功或失败
  • 异常信息
  • 每个通道的电压、内阻、判定

8. 安全与异常处理

  • 测试中禁止重复启动。
  • 测试中禁止关闭窗体，提示“手动测试正在进行，请等待测试完成。”
  • 异常时页面显示失败原因。
  • 异常时 FormalTestRunner 会尝试 STOP、清列表、清仪表缓存。
  • 页面层必须使用 Try...Finally 恢复按钮状态和 isRuning。
第一版不提供“停止”按钮。停止涉及中位机 STOP、仪表缓存清理、线程状态恢复，建议后续单独设计。

9. 第一版范围

包含不包含
菜单入口、模态窗体、256 通道矩阵、全选/清空/反选/G1/G2全选、范围添加、列表添加、开始测试、结果显示、调试日志。 正式数据库写入、MES 上传、正式 CSV 保存、NG 复测弹窗、探针计数、夹具下压/松开、停止按钮。

10. 验收标准

  • 菜单“测试(&T)”下出现“手动测试”。
  • 点击后在 MDI 主窗体顶层模态显示。
  • 可以选择任意 1~256 通道。
  • 范围和列表输入均能正确添加通道。
  • 非法通道输入有明确提示。
  • 已选数量、G1/G2 数量实时刷新。
  • 开始测试会调用 RunSparseMeasurement。
  • 测试结果显示在页面表格中。
  • 生成 ManualTest_yyyyMMdd.log。
  • MSBuild 结果为 0 warning / 0 error。
