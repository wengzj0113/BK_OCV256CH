二、重点差距与建议优先级

P0 安全与机械闭环

要求 7、8、24、25、27、30、36 涉及 NG 剔除、夹爪干涉、安全门、替罪羊、托盘方向/缺角和 FFU。当前主要停留在状态显示、托盘开合或报警监控，未形成完整的 PLC/机械手/传送带安全联锁闭环。建议先冻结现场 I/O 点位表和异常状态机，再做仿真与实机验证。

P1 测量规格与质量判定

要求 2～5、19 目前主要是数值读取和上下限判定，未看到精度公式、分辨率档位、GR&R/NDC 采集展示、K 值参与判定的完整闭环。建议将精度/分辨率/校准/判定规则纳入可追溯的测试规格，并补充 MSA 数据模型与报告。

P1 生产 KPI 与分选结果

要求 16、20～22 要求档位计数、150PPM、99.8% 合格率、98% 稼动率。当前只有 256 通道 OK/NG/测试中/空闲统计，没有生产周期、停机原因、档位计数和 OEE/PPM 计算。建议先定义统计口径，再补齐数据采集、实时看板和日报/班报。

P2 复测与现场配置

要求 9～11、17、31～35 需要明确复测次数、独立日志、仪表型号、PLC 型号、工控机资产和不良收料位。当前有可用的 NG 复测基础，但还需要把协议要求转成可配置、可审计、可现场验收的条目。
